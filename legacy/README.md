# Legacy implementations

This directory preserves earlier Ollama GUI implementations for source history,
attribution, and regression comparison. They are not installed as part of the
canonical Ollama Speak application.

- `ollama_gui.py` is the original text-only baseline derived from chyok's project.
- `ollama-Gui-Enhanced.py` is the intermediate enhanced text-only implementation.
- `ENHANCEMENTS.md` records the changes made in that intermediate generation.

The maintained application entry point is `ollama_speak.py` in the repository root.
